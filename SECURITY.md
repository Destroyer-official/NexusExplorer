## Reporting a Vulnerability

The Nexus Explorer team takes security, cryptographic guarantees, and data protection seriously.

If you discover a security vulnerability in Nexus Explorer, please **do not** open a public issue. Instead, report it through one of the following sanctioned channels:

1. **GitHub Security Advisory**: Use the [Private Vulnerability Reporting](https://github.com/Destroyer-official/NexusExplorer/security/advisories/new) tab on GitHub.
2. **Security Contact**: Contact the core maintainers directly via repository security contacts.

### What to Include in Your Report
* Description of the vulnerability and attack vector.
* Proof-of-concept (PoC) code or exact steps to reproduce.
* Potential impact (e.g. arbitrary code execution, path traversal, unauthorized file modification, cryptographic weakness).
* Suggested mitigations or patches if available.

### Vulnerability Response Timeline
* **Initial Response**: Within 48 hours of receipt.
* **Triage & Assessment**: Within 7 business days.
* **Public Disclosure**: Coordinated release and CVE assignment after patch verification and deployment.
